# Data snapshot

`raw/nyc_311_noise_2024-06-30_to_2024-07-06.csv` is the reproducibility
snapshot used by the submitted report. It was retrieved on September 23, 2026
from NYC Open Data dataset `erm2-nwe9` using `scripts/download_data.py`.

The live dataset is updated and may revise historical records. Re-running the
download script can therefore produce a different row count or values. Keep the
committed snapshot unchanged when reproducing the submitted PDF.
